# 운영체제

## 페이지 교체 (FIFO·LRU·LFU)
- 빈도: 자주
- 정의: 메모리가 꽉 찼을 때 어떤 페이지를 뺄지 정하는 방법
- FIFO: 먼저 들어온 페이지부터 교체
- LRU: 가장 오랫동안 안 쓴 페이지 교체
- LFU: 사용 횟수가 가장 적은 페이지 교체
- OPT: 앞으로 가장 오래 안 쓸 페이지 교체 (이론상 최적, 실제 구현 어려움)
- NUR: 최근에 안 쓴 페이지 교체 (참조 비트, 변형 비트 사용)
- 페이지 부재(fault): 필요한 페이지가 메모리에 없는 경우
- 시험 포인트: 참조 순서를 주고 페이지 부재 횟수 계산

## CPU 스케줄링 (SJF·HRN·RR)
- 빈도: 자주
- 비선점: 실행 중이면 끝날 때까지 CPU를 안 뺏음 → FCFS, SJF, HRN
- 선점: 중간에 CPU를 뺏을 수 있음 → RR, SRT, 다단계 큐
- FCFS: 먼저 온 순서대로
- SJF: 실행 시간 짧은 것 먼저
- HRN: 우선순위 = (대기 시간 + 서비스 시간) ÷ 서비스 시간, 큰 것 먼저
- RR: 정해진 시간만큼씩 돌아가며 실행
- SRT: 남은 시간 짧은 것 먼저 (SJF의 선점 버전)
- 시험 포인트: 평균 대기 시간 계산, HRN 우선순위 계산

## 프로세스 상태
- 빈도: 가끔
- 흐름: 생성 → 준비 → 실행 → 대기 → 준비 → … → 종료
- 디스패치: 준비 → 실행
- 타임아웃: 실행 → 준비 (할당 시간 끝)
- 블록: 실행 → 대기 (입출력 기다림)
- 웨이크업: 대기 → 준비
- PCB: 프로세스 정보를 저장하는 블록
- 문맥 교환: 실행 프로세스를 바꿀 때 정보 저장·복구
