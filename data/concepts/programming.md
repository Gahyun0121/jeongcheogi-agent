# 프로그래밍

> 코드 따라가기 문제는 LLM이 직접 생성. 이 파일은 문법 포인트용.

## C 포인터·배열
- 빈도: 매회
- 포인터: 주소를 저장하는 변수
- &a: a의 주소 / *p: p가 가리키는 값
- 배열 이름 = 첫 번째 원소의 주소
- arr[i]는 *(arr + i)와 같음
- 문자열 끝: '\0'
- 시험 포인트: 포인터 연산 후 출력값

## Java 상속·오버라이딩
- 빈도: 매회
- 상속: extends, 부모 기능을 물려받음
- 오버라이딩: 부모 메서드를 자식이 다시 정의 (이름·매개변수 같음)
- 오버로딩: 이름 같고 매개변수 다른 메서드 여러 개
- 업캐스팅: Parent p = new Child(); → 오버라이딩된 메서드는 자식 것이 실행
- static 메서드는 오버라이딩 안 됨 → 변수 타입(Parent) 기준으로 실행
- super: 부모 접근 / this: 자기 자신
- 자식 객체 생성 시 부모 생성자가 먼저 실행
- abstract(추상 클래스), interface(implements)

## Python 리스트·슬라이싱
- 빈도: 매회
- 인덱스는 0부터, 음수는 뒤에서부터 (-1 = 마지막)
- 슬라이싱 a[start:end:step], end는 포함 안 함
- a[::-1]: 거꾸로 뒤집기
- append: 끝에 값 추가 / extend: 리스트 이어붙이기
- insert: 위치 지정 추가 / remove: 값으로 삭제 / pop: 위치로 삭제 후 반환
- 자료형: list [], tuple () 수정 불가, set {} 중복 없음, dict {키: 값}
- range(start, end, step): end 포함 안 함

## 연산자 (비트·시프트)
- 빈도: 자주
- & AND, | OR, ^ XOR(다르면 1), ~ NOT
- ~a = -(a + 1)
- << 왼쪽 시프트: 2^n 곱하기 / >> 오른쪽 시프트: 2^n 나누기
- 예: 5 & 3 = 1, 5 | 3 = 7, 5 ^ 3 = 6, 1 << 3 = 8
- ++a: 먼저 증가 후 사용 / a++: 사용 후 증가
- 우선순위: 단항 > 산술 > 시프트 > 관계 > 비트(& > ^ > |) > 논리(&& > ||) > 삼항 > 대입

## 재귀 함수
- 빈도: 자주
- 정의: 자기 자신을 다시 호출하는 함수
- 종료 조건 필수
- 팩토리얼: f(n) = n × f(n−1), f(1) = 1
- 피보나치: f(n) = f(n−1) + f(n−2)
- 시험 포인트: 호출 과정을 따라가 최종값 계산 (나중에 호출된 것부터 끝남)

## 정적 변수 (static)
- 빈도: 가끔
- C: 함수 안 static 변수는 함수가 끝나도 값 유지, 초기화는 한 번만
- Java: static 변수는 모든 객체가 같은 값을 공유
- 시험 포인트: 함수를 여러 번 호출한 후의 값

## C 자료형·입출력 서식
- 빈도: 자주
- 정수끼리 나누면 몫만: 7 / 2 = 3, 나머지: 7 % 2 = 1
- 형변환: (float)7 / 2 = 3.5
- char는 1바이트 정수: 'A' = 65, 'a' = 97, '0' = 48
- printf 서식: %d 정수, %c 문자, %s 문자열, %f 실수(소수 6자리), %o 8진수, %x 16진수
- 자릿수 지정: %5d 오른쪽 정렬 5칸, %-5d 왼쪽 정렬, %.2f 소수 둘째 자리까지
- 삼항 연산자: 조건 ? 참일 때 값 : 거짓일 때 값
- 단축 평가: && 앞이 거짓이면 뒤를 실행 안 함, || 앞이 참이면 뒤를 실행 안 함
- 시험 포인트: 출력 서식, 형변환, 단축 평가로 실행 안 된 증감식

## C 제어문·반복문
- 빈도: 매회
- switch: case에 break가 없으면 아래 case까지 이어서 실행
- for (초기식; 조건식; 증감식): 조건식이 참인 동안 반복
- while: 조건을 먼저 검사 / do~while: 최소 1번은 실행
- break: 반복문 탈출 / continue: 아래 코드를 건너뛰고 다음 반복으로
- 중첩 반복문: 바깥 반복 1번마다 안쪽 반복 전체 실행
- 시험 포인트: break 없는 switch, 반복 횟수, 누적 합, 별 찍기

## C 함수·변수 유효범위
- 빈도: 자주
- 값에 의한 호출: 함수 안에서 매개변수를 바꿔도 원본은 그대로
- 주소에 의한 호출: 주소(포인터)를 넘기면 원본이 바뀜
- 지역 변수: 블록 안에서만 사용, 함수가 끝나면 사라짐
- 전역 변수: 함수 밖에 선언, 모든 함수에서 사용
- 이름이 같으면 가까운 블록의 변수가 우선
- 시험 포인트: swap 함수, 같은 이름의 전역·지역 변수

## C 선행 처리기
- 빈도: 가끔
- #include: 헤더 파일 포함
- #define 상수: #define MAX 10 → MAX를 10으로 바꿈
- #define 매크로 함수: 컴파일 전에 글자 그대로 바꿈
- 괄호 주의: #define SQ(x) x*x 이면 SQ(2+1) → 2+1*2+1 = 5
- 시험 포인트: 매크로를 그대로 바꿔 넣은 뒤 계산

## C 2차원 배열·배열 포인터
- 빈도: 자주
- int a[2][3]: 2행 3열, 메모리에는 행 순서대로 이어서 저장
- a[i][j] = *(*(a + i) + j)
- a + 1: 다음 행 / a[0] + 1: 같은 행의 다음 칸
- 배열 포인터: int (*p)[3] = a; → p는 int 3개짜리 행 하나를 가리킴, p[1][2] = a[1][2]
- sizeof(a): 배열 전체 바이트 / sizeof(a[0]): 한 행 바이트
- 시험 포인트: 포인터 연산으로 2차원 배열의 원소 찾기

## C 포인터 배열·이중 포인터
- 빈도: 자주
- 포인터 배열: int *p[3]; → 주소 3개를 담는 배열
- 문자열 배열: char *s[] = {"ABC", "DE"}; → s[1][0] = 'D'
- 이중 포인터: int **pp = &p; → *pp는 p, **pp는 변수 값
- 구분: int *p[3](포인터 배열) / int (*p)[3](배열 포인터)
- 시험 포인트: *와 &가 여러 번 붙은 식의 값 따라가기

## C 구조체·공용체
- 빈도: 자주
- 구조체(struct): 여러 자료형을 하나로 묶은 자료형
- 멤버 접근: 변수.멤버 / 포인터->멤버 ((*p).멤버와 같음)
- 구조체 배열: s[1].name = (s + 1)->name
- 중첩 구조체: a.b.c 처럼 이어서 접근
- 공용체(union): 모든 멤버가 같은 메모리를 함께 씀, 크기는 가장 큰 멤버 기준, 마지막에 넣은 값만 의미 있음
- 시험 포인트: -> 연산자, 구조체 포인터를 증가시킨 뒤 접근

## C 주요 함수
- 빈도: 자주
- strlen(s): 문자열 길이 ('\0'은 세지 않음)
- strcpy(a, b): b를 a에 복사 / strcat(a, b): a 뒤에 b를 이어 붙임
- strcmp(a, b): 같으면 0, a가 사전순으로 앞이면 음수, 뒤면 양수
- atoi("123"): 문자열을 정수 123으로
- toupper(c) / tolower(c): 대문자 / 소문자로
- malloc(크기): 메모리를 할당하고 주소를 돌려줌, free(p)로 해제
- 시험 포인트: 문자열 함수를 거친 뒤의 출력값

## Java 클래스·생성자·접근지정자
- 빈도: 자주
- 클래스: 설계도 / 객체: new로 만든 실체
- 생성자: 클래스 이름과 같고 반환형이 없음, 객체를 만들 때 자동 실행
- 생성자를 하나도 안 만들면 기본 생성자가 자동으로 생김
- this: 자기 자신 / this(...): 같은 클래스의 다른 생성자 호출
- 접근지정자 범위: public(어디서나) > protected(같은 패키지 + 자식) > default(같은 패키지) > private(같은 클래스)
- 시험 포인트: 생성자 실행 순서, this로 필드와 매개변수 구분

## Java 오버로딩·하이딩
- 빈도: 매회
- 오버로딩: 이름이 같고 매개변수의 개수나 타입이 다른 메서드 여러 개 (반환형만 다르면 안 됨)
- 오버라이딩된 메서드: 실제 객체(new 뒤의 클래스) 기준으로 실행
- 하이딩: static 메서드와 필드는 오버라이딩되지 않고 숨겨짐 → 변수 타입(선언한 타입) 기준
- 예: Parent p = new Child(); → p.x는 Parent의 x, p.show()는 Child의 show()
- 시험 포인트: 업캐스팅 뒤 메서드·필드·static 메서드 호출 결과

## Java 예외 처리
- 빈도: 가끔
- try에서 예외가 나면 남은 try 코드는 건너뛰고 catch 실행
- finally: 예외가 있든 없든 항상 실행
- catch는 위에서부터 맞는 것 하나만 실행 (자식 예외를 위에 씀)
- 대표 예외: ArithmeticException(0으로 나누기), ArrayIndexOutOfBoundsException(배열 범위 밖), NullPointerException, NumberFormatException
- throw: 예외를 직접 발생 / throws: 예외를 호출한 쪽으로 넘김
- 시험 포인트: try~catch~finally 출력 순서

## Java 추상 클래스·인터페이스
- 빈도: 자주
- 추상 메서드: abstract, 몸체가 없고 자식이 반드시 구현
- 추상 클래스: new로 객체를 만들 수 없음
- 인터페이스: interface로 선언, implements로 구현, 여러 개 구현 가능
- 클래스 상속(extends)은 하나만, 인터페이스 구현(implements)은 여러 개
- 시험 포인트: 빈칸에 extends / implements / abstract 쓰기, 다형성 실행 결과

## Java 문자열 메서드·객체 비교
- 빈도: 자주
- length(), charAt(i), indexOf("x"): 없으면 -1
- substring(a, b): a부터 b-1까지 / substring(a): a부터 끝까지
- toUpperCase(), toLowerCase(), replace(a, b), trim(), split(",")
- == : 같은 객체인지(주소) 비교 / equals(): 내용 비교
- 문자열 리터럴은 같은 객체를 함께 씀: "A" == "A"는 true, new String("A") == "A"는 false
- String은 바뀌지 않음: s.toUpperCase();만 하고 대입하지 않으면 s는 그대로
- 시험 포인트: == 와 equals 결과, substring 범위

## Java 람다·제네릭
- 빈도: 가끔
- 람다식: (매개변수) -> 식, 예: (a, b) -> a + b
- 함수형 인터페이스: 추상 메서드가 1개인 인터페이스 (람다식으로 구현)
- 제네릭: 클래스<T>처럼 타입을 나중에 정함, 예: List<Integer>
- 시험 포인트: 람다식을 호출한 결과값

## Python 주요 함수
- 빈도: 자주
- len(), range(a, b, step): b는 포함 안 함
- "a b".split() → ["a", "b"] / "-".join(["a", "b"]) → "a-b"
- 리스트: sort() 정렬, reverse() 뒤집기, index(x) 위치, count(x) 개수
- 딕셔너리: keys(), values(), items(), get(키, 기본값)
- map(함수, 리스트), lambda x: x * 2
- 문자열: upper(), lower(), replace(a, b), find(x): 없으면 -1
- 시험 포인트: 함수를 거친 뒤의 리스트·문자열 출력값
