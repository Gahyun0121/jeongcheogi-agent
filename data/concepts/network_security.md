# 네트워크·보안

## OSI 7계층
- 빈도: 자주
- 1 물리: 전기 신호 전송 / 리피터, 허브
- 2 데이터링크: 인접 장비 간 전송, MAC 주소 / 브리지, 스위치 / 프레임
- 3 네트워크: 경로 선택(라우팅), IP / 라우터 / 패킷
- 4 전송: 끝과 끝 사이 신뢰성, TCP·UDP / 세그먼트
- 5 세션: 연결 관리, 동기화
- 6 표현: 형식 변환, 암호화, 압축
- 7 응용: 사용자 서비스, HTTP·FTP·SMTP
- 암기: 물데네전세표응

## 서브네팅 (IP 계산)
- 빈도: 자주
- IPv4: 32비트, 8비트씩 4칸
- 클래스: A(0~127), B(128~191), C(192~223), D(멀티캐스트), E(실험용)
- CIDR 표기: /24 = 앞 24비트가 네트워크 부분
- 사용 가능 호스트 수 = 2^(호스트 비트 수) − 2 (네트워크 주소, 브로드캐스트 주소 제외)
- 예: 192.168.1.0/24를 /26으로 나누면 → 서브넷 4개, 각 주소 64개, 사용 가능 호스트 62개
- /26 서브넷 마스크 = 255.255.255.192
- IPv6: 128비트, 16비트씩 8칸 / 유니캐스트, 멀티캐스트, 애니캐스트

## 공격 기법 (SQL 인젝션, DoS 등)
- 빈도: 매회
- SQL 인젝션: 입력창에 SQL을 넣어 DB 조작
- XSS: 웹페이지에 악성 스크립트 삽입
- CSRF: 사용자가 의도하지 않은 요청을 보내게 함
- DoS: 서버 자원을 고갈시켜 서비스 마비 / DDoS: 여러 대가 동시에 공격
- DoS 종류
  - Ping of Death: 아주 큰 ICMP 패킷 전송
  - Smurf: 브로드캐스트로 ICMP 대량 응답 유도
  - SYN Flooding: TCP 연결 요청만 대량 전송
  - Land Attack: 출발지 IP = 목적지 IP로 위조
  - Teardrop: 조각 패킷 순서 정보 조작
- 스니핑: 네트워크 패킷 엿보기
- 스푸핑: 주소 위조 (IP, ARP, DNS)
- 무차별 대입(Brute Force): 가능한 모든 값 대입
- 버퍼 오버플로: 메모리 범위를 넘겨 덮어쓰기
- 랜섬웨어: 파일 암호화 후 돈 요구
- 스미싱: 문자(SMS)를 이용한 피싱

## 암호화 알고리즘 (대칭·비대칭)
- 빈도: 자주
- 대칭키(비밀키): 암호화 키 = 복호화 키, 빠름
  - DES, AES, SEED, ARIA, IDEA, RC4
- 비대칭키(공개키): 공개키로 암호화, 개인키로 복호화
  - RSA, ECC, ElGamal
- 해시: 단방향, 원래 값으로 복구 불가 / SHA, MD5
- 블록 암호: DES, AES / 스트림 암호: RC4
- 필요한 키 개수 (n명): 대칭키 n(n−1)/2, 비대칭키 2n

## 접근 제어 (DAC, MAC, RBAC)
- 빈도: 가끔
- DAC (임의적): 데이터 주인이 권한 결정, 사용자 신원 기준
- MAC (강제적): 시스템이 보안 등급으로 결정
- RBAC (역할 기반): 역할(직무)에 따라 권한 부여
- 벨-라파듈라 모델: 기밀성 중심, No Read Up, No Write Down
- 비바 모델: 무결성 중심, No Read Down, No Write Up

## 라우팅 프로토콜 (RIP, OSPF)
- 빈도: 가끔
- 내부(IGP): 같은 자율 시스템(AS) 안에서 사용
  - RIP: 거리 벡터 방식, 홉 수 기준, 최대 15홉, 벨만-포드 알고리즘
  - OSPF: 링크 상태 방식, 다익스트라 알고리즘, 대규모 네트워크
- 외부(EGP): 자율 시스템끼리 사용 / BGP

## 보안 용어 (신기술·약어)
- 빈도: 매회 (범위 넓음)
- 제로 트러스트: 아무도 믿지 않고 매번 검증
- APT: 특정 대상을 오랜 기간 노리는 공격
- 허니팟: 공격자를 유인하는 가짜 시스템
- SIEM: 보안 로그를 모아 통합 분석
- IDS: 침입 탐지 / IPS: 침입 탐지 + 차단
- VPN: 공용망 위에서 암호화된 사설 통신
- SSO: 한 번 로그인으로 여러 서비스 이용
- 사회공학: 사람의 심리를 이용한 공격
- 시험 포인트: 설명을 보고 용어 쓰기
