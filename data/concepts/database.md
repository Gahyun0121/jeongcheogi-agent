# 데이터베이스

## SQL (SELECT, JOIN, GROUP BY)
- 빈도: 매회
- 정의: 데이터 조회·조작 언어
- 실행 순서: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
- WHERE: 그룹 만들기 전 행 조건
- HAVING: 그룹 만든 후 그룹 조건
- INNER JOIN: 양쪽 모두 있는 행만
- LEFT JOIN: 왼쪽 전부 + 오른쪽 맞는 행 (없으면 NULL)
- 집계 함수: COUNT, SUM, AVG, MAX, MIN
- COUNT(*)는 NULL 포함, COUNT(컬럼)은 NULL 제외
- 분류
  - DDL: CREATE, ALTER, DROP
  - DML: SELECT, INSERT, UPDATE, DELETE
  - DCL: GRANT, REVOKE, COMMIT, ROLLBACK
- 시험 포인트: 쿼리 결과값 쓰기, 빈칸 채우기

## 정규화 (1~3NF, BCNF)
- 빈도: 자주
- 정의: 중복을 줄이려고 테이블을 나누는 과정
- 1NF: 모든 값이 원자값 (한 칸에 값 하나)
- 2NF: 부분 함수 종속 제거 (기본키 일부에만 종속된 속성 분리)
- 3NF: 이행 함수 종속 제거 (A→B, B→C일 때 A→C 제거)
- BCNF: 모든 결정자가 후보키
- 4NF: 다치 종속 제거
- 5NF: 조인 종속 제거
- 암기: 도부이결다조
- 반정규화: 성능을 위해 일부러 중복 허용

## 이상현상 (삽입·삭제·갱신)
- 빈도: 자주
- 정의: 데이터 중복 때문에 생기는 문제
- 삽입 이상: 원치 않는 값까지 같이 넣어야 하는 문제
- 삭제 이상: 하나 지우면 필요한 값까지 같이 지워지는 문제
- 갱신 이상: 일부만 바뀌어 데이터가 서로 안 맞는 문제
- 해결: 정규화

## 관계대수 (σ, π, ⋈)
- 빈도: 자주
- 정의: 원하는 결과를 얻는 절차를 기호로 표현 (절차적 언어)
- 순수 관계 연산자
  - σ 셀렉트: 조건에 맞는 행 선택
  - π 프로젝트: 원하는 열 선택
  - ⋈ 조인: 두 테이블 합치기
  - ÷ 디비전: 나누기
- 일반 집합 연산자: ∪ 합집합, ∩ 교집합, − 차집합, × 카티션 프로덕트
- 관계해석: 무엇을 원하는지만 표현 (비절차적 언어)
- 시험 포인트: 기호와 이름 짝짓기

## 트랜잭션 ACID
- 빈도: 자주
- 트랜잭션: 하나의 작업 단위
- 원자성(Atomicity): 전부 실행 또는 전부 취소
- 일관성(Consistency): 실행 후에도 규칙 유지
- 격리성(Isolation): 동시에 실행돼도 서로 간섭 없음
- 지속성(Durability): 완료된 결과는 영구 저장
- COMMIT: 작업 확정 / ROLLBACK: 작업 취소

## 키 (후보키, 기본키, 외래키)
- 빈도: 가끔
- 슈퍼키: 유일성 O, 최소성 X
- 후보키: 유일성 O, 최소성 O
- 기본키: 후보키 중 하나 선택, NULL 불가
- 대체키: 기본키로 안 뽑힌 나머지 후보키
- 외래키: 다른 테이블의 기본키 참조
- 개체 무결성: 기본키는 NULL·중복 불가
- 참조 무결성: 외래키는 참조 테이블에 있는 값 또는 NULL

## 스키마 3계층
- 빈도: 가끔
- 외부 스키마: 사용자 관점 (뷰)
- 개념 스키마: DB 전체의 논리 구조
- 내부 스키마: 실제 저장 구조
- 논리적 독립성: 개념 스키마가 바뀌어도 외부 스키마는 영향 없음
- 물리적 독립성: 내부 스키마가 바뀌어도 개념 스키마는 영향 없음
